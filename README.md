# TodoHerramientas

Sitio web bilingüe (español/inglés), adaptable a móviles y computadoras.

## Publicar gratis con GitHub Pages
1. Crea una cuenta en https://github.com/
2. Crea un repositorio público llamado `todoherramientas`.
3. Sube el archivo `index.html` de esta carpeta.
4. En el repositorio abre **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
6. GitHub mostrará la dirección pública de tu sitio.

También puedes publicar la carpeta con Cloudflare Pages usando **Direct Upload** o conectando el repositorio de GitHub.

## Notas
- La mayoría de herramientas funciona directamente en el navegador.
- El conversor de monedas consulta una API externa gratuita y necesita Internet.
- El generador QR usa un servicio externo y necesita Internet.
- Antes de monetizar, agrega páginas reales de privacidad, contacto y términos; revisa las políticas vigentes de la plataforma publicitaria.
- No hay garantía de ingresos. El sitio necesita contenido útil, visitantes y aprobación de la plataforma de monetización.
